# Troubleshooting

**Web shows "Could not reach API".** Confirm the API is up (`curl
http://localhost:8000/health`) and `NEXT_PUBLIC_API_BASE_URL` matches. Check
`CORS_ORIGINS` includes the web origin.

**`/ready` shows pgvector unavailable.** Ensure the `vector` extension exists:
`CREATE EXTENSION IF NOT EXISTS vector;` (the pgvector Docker image and Alembic
`env.py` do this automatically). Without pgvector on Postgres the app still works
via the NumPy cosine fallback.

**Semantic search says "not configured".** Set `EMBEDDING_PROVIDER` (and model)
in `.env`. With `none`, only keyword search runs — by design. `hash` is a
test/demo embedder, not real semantic search.

**OCR not happening / `ocr_status = failed`.** Install Tesseract + Ghostscript
(present in the API Docker image). `/ready` reports Tesseract availability. The
system marks OCR as not performed rather than faking it.

**Provider "Test Connection" fails.** The test makes a real request. Check the
API key (Settings → AI Providers), base URL, and network egress. 401 =
invalid key; timeout = network/egress.

**Live crawl rejected with 400.** Live (non-fixture) crawls require
`confirm=true` and non-empty `seed_urls`. Add verified public URLs to
`config/sources.yaml` first.

**Crawl reports blocked URLs.** Expected when a URL is outside `allowed_domains`,
resolves to a non-public IP, or is disallowed by robots.txt. This is the SSRF/
scope guard working, not a bug.

**Migration error `NameError: app is not defined`.** Autogenerated migrations
that reference `app.db.types.Vector` need `import app.db.types` (the
`script.py.mako` template adds it automatically for new revisions).

**"No space left on device".** Archive data lives under `DATA_DIR`. Prune old
crawl payloads/derivatives; the DB and store volumes can grow with large PDFs.

**Restarting a failed ingestion job.** `POST /api/ingestion/jobs/{id}/retry`
(or the "retry" button in Archive → Ingestion) resets and re-dispatches it.
