# No-Docker LOCAL run (SQLite + in-process jobs).
# Lean dependency set — everything here has prebuilt Windows/macOS/Linux wheels
# and needs NO system services (no PostgreSQL, no Redis) and NO compiler.
#
# Excluded vs the full stack (not imported on the SQLite + inline path):
#   psycopg / pgvector  -> only for PostgreSQL
#   celery / redis      -> only for the Celery job backend (we use in-process)
#   alembic             -> migrations; SQLite tables are auto-created on startup
#   ocrmypdf / pdfplumber -> not imported by the app
#
# OCR: pytesseract is included; it only needs the Tesseract binary at OCR TIME.
# Without Tesseract installed, OCR is reported as "not performed" (never faked);
# demo data has embedded text so it needs no OCR.
# ============================================================
